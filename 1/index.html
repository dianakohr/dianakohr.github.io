Project 1

The photos in this section are fails! The aligned photos are at the bottom.
My first step was to get the skeleton code running and take a 24 hour break. This is what cathedral looked like at first.

My initial implementation of window search made things worse because I forgot to track improvements, so I always ended up shifting by [15, 15] :D

Finally I got window search to work!!! This yielded good results on the other JPGs, but not the TIFs. I then implemented a faulty image pyramid, where I took the shifts from the smallest version of the image, and directly applied it to the original image. There was basically no improvement...

Doing adjustments at each scale of the image resolved this issue, but there were still a few blurry images that I had to troubleshoot individually. I expanded the search window to [-30, 30] to fix melons, for example.

I also noticed that I wasn't cropping the edges of the TIF images enough. Increasing the border size from 50 (JPG) to 300 (TIF) worked.

However, emir got blurrier when I cropped more, so emir is the only TIF image that I still crop by 50.

And now the final results :P
