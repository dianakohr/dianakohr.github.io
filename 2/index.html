Part 1.1: Convolutions from Scratch!

Convolution with 4 for loops:


    def convolve_4_loops(im, filter):
        im_x, im_y = im.shape
        filter_x, filter_y = filter.shape
        pad_x, pad_y = (filter_x-1) // 2, (filter_y-1) // 2
        im = np.pad(im, pad_width=((pad_x, pad_x), (pad_y, pad_y)), 
                    mode='constant', constant_values=0)
        
        convolution = np.empty((im_x, im_y))
        for i in range(im_x):
            for j in range(im_y):
                val = 0
                for k in range(filter_x):
                    for h in range(filter_y):
                        val += im[i+k][j+h] * filter[filter_x-1-k][filter_y-1-h]
                convolution[i][j] = val
        return convolution

Convolution with 2 for loops:


    def convolve_2_loops(im, filter):
        im_x, im_y = im.shape
        filter_x, filter_y = filter.shape
        pad_x, pad_y = (filter_x-1) // 2, (filter_y-1) // 2
        im = np.pad(im, pad_width=((pad_x, pad_x), (pad_y, pad_y)), 
                    mode='constant', constant_values=0)
        flipped = np.array([row[::-1] for row in filter][::-1])
        
        convolution = np.empty((im_x, im_y))
        for i in range(im_x):
            for j in range(im_y):
                convolution[i][j] = np.sum(im[i:i+filter_x, j:j+filter_y] * flipped)
        return convolution

Here's the picture I used to compare different implementations of convolution. Although they produced the exact same results, scipy was consistently the fastest. 2 loops was faster than 4 loops on the box filter (9x9), but slower on the finite difference filters (1x3, 3x1). Scipy's implementation also allows a lot of flexibility in terms of padding. Setting mode='same' is the behavior we want, but there are other options that vary padding size and values.

Part 2: Fun with Frequencies!

Part 2.1: Image "Sharpening"

Apart from the provided Taj image, I tried sharpening a blurry picture of a panda (the glass was foggy). We start by blurring the image; when we subtract this from the original, we get a high frequency version that essentially captures details. To sharpen the image, we add the high frequency details to the original.

Although I wasn't able to recapture all the detail in the original image, the sharpened versions are noticeably better than the blurred version. The edges are defined enough, but the coloring is slightly off, which probably has something to do with how I normalize. Notice that for larger α values, the image gets sharper (because α corresponds to how much high frequency you're adding), but the color deviates more (becomes more gray).
